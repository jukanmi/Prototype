# 카드 발동형 어시스트 시스템

## 이 프로젝트에서의 구성

현재 프로젝트는 ScriptableObject 모듈을 Initialize/Release하는 구조가 아니라,
`Entity`, `Control`, `IState`를 직접 조립합니다. 따라서 동료 상태 키/상태 데이터
에셋을 따로 만들 필요가 없습니다. 기존 `PartyMemberData.prefab`, `equipped`,
`PartyAssembler`가 만든 동료 인스턴스를 비활성 풀로 재사용합니다.

- `CastRequest`: 시전자, 스킬, 조준, 피해 배율, 불릿타임 여부를 넘기는 경계.
- `CastDirector`: 불릿타임 진형 준비, 손패 순서에 따른 순차 시전, 완료 및 중단 처리.
- `AssistManager`: 파티 동료 풀, 등장/진형/퇴장 위치, 회수.
- `AssistControlModule`: 등장 → 대기 → 시전 → 퇴장 → 비활성 흐름과 동료별 대기열.
- `AssistMoveState`/`AssistReadyState`: 이동과 대기. 시전은 기존 `SkillState`를 사용.

`TagSwapController`는 기존 프리팹/씬/HUD 참조를 보존하는 호환 어댑터입니다.
교대 기능은 없으며, 조작·카메라·조준 기준은 항상 주인공입니다. 주인공 사망이
패배 조건이고 동료에게 조작권을 넘기지 않습니다. F/Z 동료 호출 입력은 제거했습니다.

## 발동 규칙

자동 카드는 기존 평타 적중 카드 추첨에서 `CastDirector.Cast`로 연결됩니다.
주인공은 계속 움직이고, 동일 동료의 요청은 차례로 실행합니다. 퇴장 도중 새 요청이
들어오면 비활성화하지 않고 퇴장을 중단합니다.

자동 카드의 평타 적중 발동률은 기존 50%에서 장기 평균 25%로 낮췄습니다.
`BasicAttackProcRoller`는 실패 횟수에 따라 다음 확률을 올리고 성공하면 초기화합니다.
확률은 `min(1, C × (연속 실패 + 1))`이며, 평균 성공 간격이 4회가 되도록
C를 계산합니다(약 0.084744). 첫 확률은 약 8.47%이고 최대 12번째 유효 적중에서
발동합니다. 독립적인 25% 추첨이나 LoL 내부 공식의 복제가 아닌 연속 실패 완화입니다.
보정 상태는 컨트롤러별로 유지하며 불릿타임 출입으로 초기화하지 않습니다.
새 전투/컴포넌트 활성화에서 초기화합니다. 불릿타임 중이거나 시전 가능한 카드가
없는 적중은 추첨하지 않고, 기존 장부로 같은 평타의 다중 적중도 한 번만 셉니다.

불릿타임 진입과 카드 선택 중에는 Battle 배율이 0입니다. 기존 불릿타임키로 시전을 확정하면
즉시 1로 복구해 준비·시전·퇴장 중 주인공과 적이 정상적으로 움직입니다. 이미 실행 중인
자동 스킬은 Cast 시간으로 마저 끝낸 뒤 진형으로 걸어갑니다. 카드 있는 동료만
진형에 등장하며, 다른 동료는 새로 소환하지 않습니다. 손패의 현재 슬롯 순서대로
한 장씩 발동하고, 동료가 달라도 이전 카드의 스킬과 투사체/설치기가 끝날 때까지
다음 카드는 기다립니다. 차징기는
최대 충전 후 자동 해제됩니다.

전원이 진형에 도착하면 0.25초 동안 준비합니다. 대기 동료는 대상을 바라보고
자기 첫 카드 스킬 애니메이션의 10% 지점 자세를 유지합니다(클립이 없으면 Idle).
시전 단계에는 전장 시간이 정상적으로 흘러 적의 피격·넉백·띄우기가 즉시 반영됩니다.
카드의 스킬/잔여 공격 완료 후 최소 0.3초를 두고, 수평 넉백이 남으면 최대 1초까지
기다린 뒤 다음 카드를 시작합니다. 공중 대상은 착지를 기다리지 않아 공중 연계가 가능합니다.
각 카드는 선택 시점의 대상에 연결되며, 자기 차례에 그 대상의 현재 위치로
좌표/방향을 다시 계산합니다. 대상이 사망하면 살아 있는 적을 다시 선택합니다.
`CastDirector` 인스펙터의 preparationSeconds/impactGapSeconds/maxReactionWaitSeconds로
준비 시간과 카드 사이 텀을 조절할 수 있습니다.

불릿타임 중 들어온 자동 요청과 아직 시작하지 않은 자동 대기열은 보류했다가
해제 후 실행합니다. 투사체/설치기도 Cast 시간을 사용하고, 시전자가 퇴장한 뒤에도
자기 시계를 유지합니다. 해당 공격들이 끝난 뒤 다음 카드로 넘어갑니다. 비정상적으로
10초 이상 남은 공격은 경고를 남기고 취소합니다.

동료는 피격 무적이고 적 AI의 타겟 후보에서 제외됩니다. 루트 몸통 콜라이더 간
충돌만 무시하며, 공격 트리거의 적중은 그대로 유지합니다. 위치는 카메라 가로 범위,
StageBounds 유닛 범위, GroundRegistry 발판 범위를 참고해 보정합니다.

## 시간과 정리

- Battle: 주인공, 적, 전장 물리/애니메이터, 자동 발동, 게이지/쿨다운.
- Cast: 동료 상태머신/스킬/물리/애니메이터와 해당 동료가 만든 투사체/설치기.
- UI: 기존 비배율 시간.

`Time.timeScale`은 변경하지 않습니다. 카드 선택 중 쌓인 충격은 기존 키로 시전 확정 또는
점프키 취소로 정지가 해제되면 재생됩니다. 시전 단계에는 정상 전투 시간이 흐릅니다.

주인공 사망, 웨이브 완료, 패배, 씬 이탈/재시작, 호스트 비활성화에서 전부 회수하고
불릿타임을 해제합니다. 중단된 카드는 한 번만 소비 처리해 덱에서 증발하지 않게 합니다.

## Unity에서 사용하기

1. 기존 `BattleInput.prefab`의 `PartyAssembler` 로드아웃을 설정합니다.
2. 각 동료의 기존 `PartyMemberData`에 프리팹과 `equipped` 카드를 지정합니다.
3. `BattleInput.prefab`에는 `AssistManager`, `CastDirector`, `CastTester`가 연결돼 있습니다.
4. 플레이 중 `CastTester` 컴포넌트 메뉴의 `Assist/Automatic card`,
   `Assist/Queue three automatic cards`, `Assist/Bullet time equipped party cards`,
   `Assist/Recall all`로 카드 시스템 없이 검사할 수 있습니다.
   자동 테스트의 caster/skill을 비우면 첫 카드가 있는 파티원을 사용합니다.
5. 기존 불릿타임키로 진입하고 카드 순서/조준을 정한 뒤 같은 키로 실행합니다.
   기본 E, 화살표 프리셋 Space이며 기존 리바인딩을 그대로 사용합니다. 확정 즉시 시간 정지가 풀립니다.
6. 선택/진입 연출 중 점프키로 취소합니다(기본 K, 화살표 프리셋 C).
   카드를 소비하지 않고 게이지·마나도 그대로 유지합니다. 취소 입력으로 실제 점프가 나가지 않습니다.
   시전 확정 후의 점프키는 정상 점프입니다. 마우스 프리셋의 기존 점프 Space도 유지합니다.

외부 카드 시스템 예:

```csharp
director.Cast(new CastRequest(ally, skill, target, damageScale));
```

`CastTicket.IsDone`/`WasCancelled`와 완료 콜백으로 소비/후처리를 연결할 수 있습니다.

## 검증

- Unity 6000.5.5f1 격리 프로젝트에서 관련 회귀 검사 99개 통과(실패 0).
  스크립트·데이터·프리팹을 복사해 Unity 네이티브 컴파일과 실행 검사를 수행했습니다.
  손패 순차 발동 변경 후 재검증도 99개 통과했습니다.
  결과: `Logs/assist-sequential-results.xml`, 로그: `Logs/assist-sequential-unity.log`.
- 발동률 보정 변경 후 104개 통과(실패 0). 평균 확률의 수학적 계산,
  고정 시드 10만 회 추첨, 실패 보정 증가와 성공 초기화, 최대 실패 길이를 검사했습니다.
  결과: `Logs/assist-proc-results.xml`, 로그: `Logs/assist-proc-unity.log`.
- 타격/위치 연계 변경 후 154개 통과(실패 0). 실제 Combat.Attack과 Unity 물리로
  전원 준비, 분리된 타격 시점, 불릿타임 중 대상 이동, 이동 후 다음 조준,
  주인공/미피격 적/적 AI 정지를 확인했습니다. 시전 세션 초기화와 대상 사망 시
  재타겟, 인접 경직·디버프·넉백 검사도 포함합니다.
  결과: `Logs/assist-impact-results.xml`, 로그: `Logs/assist-impact-unity.log`.
- 기존 불릿타임키 복원 후 169개 통과(실패 0). 기존 키 진입/확정과 점프 취소,
  선택 취소 시 손패·게이지·마나 보존, 조준/카드 맵 종료, 확정 즉시 시간 재개,
  정상 시간이 흐르는 동안의 순차 타격·재조준과 입력 프리셋 충돌을 검사했습니다.
  결과: `Logs/assist-input-results.xml`, 로그: `Logs/assist-input-unity.log`.
- 원본 전투 씬의 화면 연출과 개별 카드의 실제 아트/애니메이션은 아직 수동 검증하지 않았습니다.
- `AssistSystemTests`: 재사용·동일 동료 대기열·무적·조작권·진형 대상·강제 회수.
- `AssistSmokeTests`: Play Mode에서 시전 시 정상 시간 진행, 동료 이동, 손패 순서와 시전 비중첩, 퇴장,
  주인공 조작권 유지와 사망 중단을 검사합니다. 해제 후 충격량은 명시적인 물리
  시뮬레이션 단계로 확인합니다. 검사에 쓰는 스킬은 제어 가능한 테스트 스킬입니다.
- `Tools > Assist > Run regression tests`: 씬을 다시 열지 않는 Edit Mode 회귀 검사.
  결과는 `Logs/assist-editmode-results.xml`에 저장됩니다.

등장/퇴장 전용 이펙트와 불릿타임 연출, 카드별 스킬 아트 제작은 별도 작업입니다.
