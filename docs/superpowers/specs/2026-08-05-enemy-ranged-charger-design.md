# 원거리·돌진 Enemy Brain 및 전용 프리팹 설계

- 작성일: 2026-08-05
- 상태: 승인됨
- 범위: 기존 근접 적을 유지하면서 원거리 적과 돌진 적을 추가하고, 세 종류를 도형과 붉은 계열 색으로 구분한다.

## 1. 목표

현재 `IEnemyBrain` 구조를 확장해 다음 세 종류의 적을 한 씬에서 구분하고 검증할 수 있게 한다.

1. 근접 적: 타겟에게 접근해 근접 공격한다.
2. 원거리 적: 선호 거리를 유지하며 실제 비유도 투사체를 발사한다.
3. 돌진 적: 조준을 예고한 뒤 고정된 방향으로 직선 돌진한다.

브레인은 계속 무상태 `ScriptableObject`로 유지한다. 타이머, 조준 단계, 돌진 진행 상태, 충돌 이력처럼 적마다 달라지는 런타임 상태는 적 인스턴스가 보관한다.

## 2. 선택한 구조

판단과 실행을 분리한다.

```text
EnemyControl
  -> EnemyBrainAsset.Decide(context)
  -> EnemyIntent
      -> 공용 Command: 이동 / 근접 공격
      -> EnemyActionKind: 원거리 발사 / 돌진
  -> EnemyActionExecutor: 준비 동작, 발사, 돌진, 후딜 실행
  -> Entity 공용 StateMachine: 기존 이동 / 근접 공격 실행
```

공용 `Entity` 상태 머신에 적 전용 상태를 넣지 않는다. 브레인 안에도 진행 상태를 저장하지 않는다. `EnemyActionExecutor`가 특수 행동의 수명 주기를 담당하며, `EnemyControl`은 브레인의 의도를 실제 실행 계층으로 전달하는 어댑터 역할을 유지한다.

### 2.1 계약 확장

`EnemyBrainContext`에는 다음 판단 입력을 추가한다.

- 일반 공격 쿨 완료 여부
- 특수 행동 쿨 완료 여부
- 선호 최소 거리
- 특수 행동 최대 거리

`EnemyIntent`에는 기존 `Command`와 별도로 `EnemyActionKind`를 추가한다.

- `None`
- `RangedShot`
- `Charge`

이동과 근접 공격은 기존 `Command.Move`와 `Command.Attack`을 그대로 사용한다. 특수 행동이 있는 의도에는 이동 명령을 동시에 넣지 않는다.

### 2.2 쿨타임 소유권

`EnemyControl`이 일반 공격 타이머와 특수 행동 타이머를 각각 가진다.

- 근접 공격 또는 원거리 발사가 실제로 접수되면 일반 공격 타이머를 소비한다.
- 돌진이 실제로 접수되면 특수 행동 타이머를 소비한다.
- 실행기가 행동을 거절한 경우 쿨타임을 소비하지 않는다.
- 피격, 경직, 사망, AI 정지로 준비 동작이 취소되어도 이미 시작된 행동의 쿨타임은 환불하지 않는다.

## 3. 원거리 적

### 3.1 판단 규칙

기본 거리 구간은 다음과 같다.

- `distance > 7m`: 타겟 방향으로 접근한다.
- `4m <= distance <= 7m`: 정지한다. 일반 공격 쿨이 끝났으면 원거리 발사를 요청한다.
- `distance < 4m`: 타겟 반대 방향으로 후퇴한다.
- 타겟이 없거나 leash 범위 밖이면 아무 행동도 하지 않는다.

경계값은 의도적으로 공격 구간에 포함한다. 즉 정확히 4m 또는 7m일 때 후퇴하거나 접근하지 않고 사격 판단을 한다.

### 3.2 발사 수명 주기

1. 발사 요청을 접수하면 0.25초 동안 제자리에서 준비한다.
2. 준비 중 타겟 방향을 바라본다.
3. 실제 발사 순간의 타겟 위치를 향하는 방향을 계산한다.
4. 타겟이 준비 중 사망하거나 사라지면 발사를 취소한다.
5. 투사체를 생성한 뒤 일반 판단으로 돌아간다.

투사체는 유도하지 않는다. 발사 후 타겟이 움직여도 궤적은 바뀌지 않는다.

### 3.3 투사체

- 속도: 10m/s
- 수명: 3초
- 표현: 작은 진홍색 구체
- 이동 평면: XZ, 발사 높이는 적 몸체 중심 높이
- 충돌 대상: 반대 진영 `Combat`만
- 같은 적 진영과 발사자는 무시
- 하나의 투사체는 최초 유효 대상 한 명만 타격
- 유효 대상, Wall 레이어 또는 수명 종료 시 제거
- 피해와 경직 데이터는 발사한 적의 기본 `HitData` 및 공격력 계산 경로를 재사용

## 4. 돌진 적

### 4.1 판단 규칙

- `distance <= 2m`: 일반 공격 쿨이 끝났으면 근접 공격한다.
- `2m < distance <= 7m`: 특수 행동 쿨이 끝났으면 돌진을 요청한다.
- 돌진 쿨 중이거나 `distance > 7m`: 타겟 방향으로 접근한다.
- 타겟이 없거나 leash 범위 밖이면 아무 행동도 하지 않는다.

### 4.2 돌진 수명 주기

1. **예고:** 0.6초 동안 정지하고 타겟을 바라본다.
2. **방향 고정:** 예고 종료 시점의 타겟 위치로 방향을 계산하고 이후 고정한다.
3. **돌진:** 14m/s로 최대 0.55초 동안 직선 이동한다.
4. **종료:** 유효한 아군 충돌, Wall 충돌 또는 최대시간 도달 시 즉시 관성을 제거한다.
5. **후딜:** 0.8초 동안 정지한 뒤 일반 판단으로 복귀한다.

돌진 도중 타겟을 추적해 방향을 휘지 않는다. 돌진 히트박스는 돌진 구간에서만 활성화되며, 한 번의 돌진에서 같은 대상은 한 번만 맞는다. 최초 유효 아군을 맞히면 해당 돌진은 종료된다.

### 4.3 취소 규칙

- 예고 또는 돌진 중 피격·경직·사망하면 즉시 취소한다.
- 취소 시 히트박스를 끄고 이동 관성을 제거한다.
- `Enemy.StopAI()` 호출 시 진행 중인 발사 준비 또는 돌진도 취소한다.
- 발사 준비와 돌진 후딜 중에는 새 브레인 판단을 실행하지 않는다.

## 5. 데이터 구조

세 적 종류마다 별도 `EnemyData` 애셋을 만든다.

- `Enemy_Melee.asset`
- `Enemy_Ranged.asset`
- `Enemy_Charger.asset`

공통 데이터는 체력, 공격력, 이동속도, 일반 공격 거리, 일반 공격 간격, 재탐색 간격, leash 범위, 브레인 참조를 가진다. 확장 데이터는 선호 최소 거리, 특수 행동 거리, 특수 행동 쿨타임과 다음 실행 수치를 가진다.

- 원거리: 발사 준비 시간, 투사체 속도, 투사체 수명, 투사체 프리팹
- 돌진: 예고 시간, 돌진 속도, 최대 돌진 시간, 후딜 시간

사용하지 않는 확장 값은 해당 브레인과 실행기가 무시한다. 프리팹에 수치를 중복 하드코딩하지 않고 `Enemy.Awake()`에서 `EnemyData`를 `EnemyControl`과 실행기에 주입한다. `EnemyData`가 없는 기존 프리팹은 현재 인스펙터 폴백값으로 계속 동작한다.

## 6. 애셋과 외형

### 6.1 브레인 애셋

- `Assets/Data/Enemy/Brain_Melee.asset`
- `Assets/Data/Enemy/Brain_Ranged.asset`
- `Assets/Data/Enemy/Brain_Charger.asset`

### 6.2 프리팹

- `Assets/Prefabs/Enemy_Melee.prefab`
- `Assets/Prefabs/Enemy_Ranged.prefab`
- `Assets/Prefabs/Enemy_Charger.prefab`
- `Assets/Prefabs/EnemyProjectile.prefab`

기존 `enemy.prefab`이 사용되던 참조는 GUID를 보존해 `Enemy_Melee.prefab`으로 이동하거나 명시적으로 새 근접 프리팹으로 교체한다. 씬에 누락된 프리팹 참조가 남지 않아야 한다.

### 6.3 시각 구분

| 종류 | 기본 도형 | 색상 | 용도 |
|---|---|---|---|
| 근접 | Capsule | 벽돌색 빨강 `#C94B4B` | 기준형 |
| 원거리 | Sphere | 와인색 빨강 `#922B4F` | 가볍고 원거리인 실루엣 |
| 돌진 | 넓은 Cube | 주황빛 빨강 `#E85D3F` | 무겁고 돌진하는 실루엣 |
| 투사체 | 작은 Sphere | 진홍색 `#DC143C` | 원거리 공격 식별 |

모든 적은 기존 정면 마커를 유지한다. 머티리얼은 종류별로 분리하고 URP Lit을 우선 사용하되, 사용할 수 없으면 Standard 셰이더로 폴백한다.

## 7. 테스트 씬과 생성 도구

`TestSceneBuilder`는 반복 실행해도 같은 애셋을 갱신하는 방식으로 다음을 만든다.

- 종류별 머티리얼
- 브레인 애셋 3개
- `EnemyData` 3개
- 적 프리팹 3개와 투사체 프리팹
- 세 종류가 모두 포함된 테스트 전투 씬

테스트 씬의 적 배치는 근접·원거리·돌진이 최소 한 개씩 보이게 한다. 생성기를 다시 실행해도 중복 애셋이나 중복 씬 오브젝트가 생기지 않아야 한다.

## 8. 오류 처리와 안전 조건

- 브레인이 없으면 기존과 같이 경고를 한 번 남기고 정지한다.
- 특수 행동 실행기 또는 투사체 프리팹이 누락되면 경고를 남기고 해당 행동을 시작하지 않는다.
- 공격 거리, 투사체 속도, 수명, 돌진 속도 또는 시간이 0 이하이면 저작 오류 경고를 남긴다.
- null 또는 사망한 타겟을 향해 투사체나 돌진을 시작하지 않는다.
- 모든 런타임 생성 투사체는 충돌 여부와 무관하게 수명 종료 시 제거된다.

## 9. 검증

Unity Test Framework를 사용한다. 순수 브레인 판단(아래 1~3, 6)은 EditMode에서 씬 없이 실제 브레인 인스턴스를 생성해 검증한다. 투사체·돌진의 시간 진행과 물리 충돌(4, 5, 7~9)은 PlayMode에서 검증한다. 프리팹 배선(10)은 EditMode 에디터 애셋 테스트로 검증한다.

필수 자동 검증 항목:

1. 기존 근접 브레인의 접근·공격·leash 행동이 유지된다.
2. 원거리 브레인이 4m 미만에서 후퇴하고, 4~7m에서 사격하며, 7m 초과에서 접근한다.
3. 원거리 경계값 4m와 7m가 사격 구간에 포함된다.
4. 원거리 투사체가 비유도로 움직이고 반대 진영 한 명만 타격한다.
5. 투사체가 Wall 충돌 또는 3초 수명 종료로 제거된다.
6. 돌진 브레인이 2m 이하에서 근접 공격, 2~7m에서 돌진, 나머지 거리에서 접근을 선택한다.
7. 돌진 방향이 예고 종료 후 고정된다.
8. 돌진이 유효 대상, Wall 또는 0.55초 제한으로 종료되고 0.8초 후딜에 들어간다.
9. 피격·경직·사망·AI 정지가 진행 중 특수 행동을 안전하게 취소한다.
10. 세 적 프리팹과 투사체 프리팹에 올바른 데이터, 브레인, 실행 컴포넌트, 머티리얼이 연결된다.

수동 확인에서는 테스트 씬에서 세 종류의 실루엣과 색을 즉시 구분할 수 있고, 원거리 탄환을 피할 수 있으며, 돌진 예고를 보고 회피할 수 있어야 한다.

## 10. 범위 제외

- 투사체 오브젝트 풀링
- 탄도·유도·관통 투사체
- 돌진 경로 탐색과 장애물 우회
- 예고용 파티클, 사운드, 셰이더 점멸
- 보스용 복합 패턴과 브레인 내부 행동 트리
- 스포너 및 스테이지 진행 시스템 구현

이번 작업은 세 적 유형의 판단·실행·프리팹·테스트 씬 배선까지 완료하는 데 한정한다.
