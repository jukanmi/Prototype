# 최근 타격 적 HUD 설계

- 작성일: 2026-08-05
- 상태: 승인됨
- 범위: 전투 중 플레이어 진영이 가장 최근 피해를 준 적 한 명의 남은 체력을 화면 하단에 표시한다.

## 목표

다수의 적을 공격할 때 플레이어가 방금 피해를 준 적의 체력 변화를 화면 아래에서 즉시 확인하게 한다. 화면 위 개체 체력바를 찾게 하거나, 여러 적의 정보를 동시에 나열하지 않는다.

## 사용자 경험

- 플레이어 또는 아군의 공격이 적에게 유효 피해를 주면 해당 적을 현재 표시 대상으로 설정한다.
- HUD는 적 이름과 짧은 현재 HP/최대 HP 체력바를 표시한다.
- 새 적을 맞히면 기존 대상은 즉시 교체한다. 같은 적을 다시 맞히면 체력만 갱신한다.
- 대상이 처치되면 즉시 숨긴다.
- 마지막 유효 타격 뒤 3초 동안 새 타격이 없으면 숨긴다.
- 표시 대상은 항상 하나이며, 거리·상태·피해 숫자·다수 대상 목록은 포함하지 않는다.

## 구조

`Combat.Attack`은 이미 공격자와 피격 `Combat`을 함께 알고 있다. 공격자가 아군이고 피격자가 적일 때, UI 전용 `RecentHitEnemyHUD`가 이 타격을 수신한다. HUD는 피격자의 `Energy` 값을 읽어 체력바를 갱신하고, 사망 이벤트를 구독해 즉시 정리한다.

HUD는 별도 Screen Space Overlay 캔버스를 런타임에 만들고, 기존 `ComboBoardUI`의 카드 보드 바로 위 하단 중앙에 배치한다. 카드 보드가 없는 전투 장면에서도 독립적으로 표시될 수 있다.

## 경계 조건

- 무적 판정으로 실제 피해가 적용되지 않은 공격은 표시 대상을 변경하지 않는다.
- 공격자·피격자 또는 필수 `Combat` 참조가 없으면 안전하게 무시한다.
- UI가 파괴되거나 대상이 바뀔 때 이전 대상의 사망 구독을 해제한다.
- 화면 스케일 기준은 기존 UI와 동일한 1920×1080이다.

## 검증

1. 아군이 적 A를 때리면 하단 중앙에 A의 이름과 HP 바가 나타난다.
2. 적 B를 때리면 표시가 B로 교체된다.
3. 같은 적을 연속 타격하면 한 장의 HUD가 남은 체력으로 갱신된다.
4. 대상이 죽으면 HUD가 바로 사라진다.
5. 3초 동안 새로운 유효 타격이 없으면 HUD가 사라진다.
6. 적이 아군을 공격하거나, 무적 판정으로 무시된 공격은 HUD를 표시하거나 갱신하지 않는다.
