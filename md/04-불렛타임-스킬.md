# 04. 불렛 타임 · 스킬 탄창

## 클래스 구조

```
BulletTimeManager
  · 불렛타임 진입, 해제
  · 시간 정지
        │
   ┌────┴──────────────────┐
   ▼                       ▼
불렛타임 슬롯 ui          손패 ui
(MagazineUI *임시)       (Skill Palatte UI *임시)
 · 탄창 표시              · 현재 손패 목록 확대
 · 순서 변경, 삭제 버튼    · 드래그&드롭으로 스킬 배치
 · 발동 버튼 FireAll()
        └──────────┬──────────┘
                   ▼
          MagazineController
            · 발사 순서 관리(queue)
            · FireAll()
                   │
                   ▼
             SpellMagazine  ────────► SpellData
               · 등록된 스킬 리스트      · 스킬 정보
               · 최대 등록 가능 스킬 수   · 이름, 아이콘, 설명, 위력 등
               · 순서 변경, 삭제
               · 발사 Fire()
                   │
                   ▼
             SkillExecutor
               · 스킬 발동 Execute()
```

## 사용자 조작 시퀀스

```
불렛타임 키 입력
  > 손패, 슬롯 UI 활성화, 실시간 정지
  > 손패에서 슬롯으로 드래그&드롭
  > 슬롯에 저장
  > 발사 버튼 입력
  > 불렛타임 종료, 실시간 재개
  > 저장한 스킬 순차적 발동
```

## 시스템 연동 요구사항

```
불렛타임 키 입력
  > BulletTimeManager.Enter()

불렛타임 동안
  > 플레이어 조작 제한          = 플레이어 컨트롤 연동
  > UI 입력 (드래그&드롭, 버튼), 슬롯 표시
  > 핸드, 덱, 스킬 ui 표시 / 확대   = UI 제어 연동
  > 시간 슬로우 / 정지           = 실시간 전투쪽 시간시스템과 연동
  > 적 AI 이동, 공격 정지        = 적 시스템 연동
```

> UI 이름은 모두 임시: `MagazineUI`, `Skill Palatte UI`.
