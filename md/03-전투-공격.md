# 03. 전투 · 공격 파트

## 공격 판정 흐름

```
공격과 피격자 충돌
        │
        ▼
 ┌──────────────┐
 │ 공격 적중 판정 │  공중피격 / 회피 / 다운 / 기상무적
 └──────┬───────┘
        ▼
    물리 적용  ──────►  피해 발생 판정(보호막)  ──────►  대미지 적용
        ▲                       │                          │
        └───────────────────────┴──────────────────────────┘
                (판정 결과에 따라 공격자·피격자 Combat 으로 되돌아감)
```

- **공격 적중 판정** 분기 조건: 공중피격, 회피, 다운, 기상무적
- **피해 발생 판정**: 보호막 유무
- 물리 적용은 피격자의 `Physics`(CombatPhysics)로 들어간다.
- 대미지 적용은 피격자의 `Health`로 들어가고, `체력 UI`가 이를 구독한다.

## 관여 객체

### 공격자
```
공격자 Combat
  └─ Stats (공격력)
```

### 공격
```
공격 Attack
  ├─ 공격정보  HitData
  └─ 대미지정보 DamageData
```

### 피격자
```
피격자 Combat
  ├─ CombatState
  ├─ Physics   (물리 적용 대상)
  ├─ Energies
  └─ Health    (대미지 적용 대상) ──► 체력 UI
```

## 데이터 구조 (실시간 전투 섹션 기준)

### `DamageData`
- 대미지

### `HitData`
- 대미지정보
- 유발하는 상태
- 넉백/띄우기 방향, 힘
- 경직시간

### `Health`
- 현재값 / 최대값
- 소모 / 회복

### `Combat`
- 피격 `Hit(HitData hitData)`
- 피해 `TakeDamage(DamageData damageData)`

### 관계
```
Player ──► Attack ──(충돌)── Enemy
             │
             ├── HitData ── DamageData
             └── Combat ── Health
```
