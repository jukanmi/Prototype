# 02. 플레이어 · 물리 파트

## 물리 파트 — 프레임 파이프라인

`FixedUpdate` 한 프레임에서 아래 4개 처리를 순서대로 돌린다.

```
                         FixedUpdate
     ┌────────────┬────────────┬──────────────────┬──────────────┐
     ▼            ▼            ▼                  ▼              │
HandleMovement  HandleGravity  HandleExternalForces  ApplyVelocity
     ▲            ▲                 ▲   ▲               ▲
     │            │                 │   │               │
  MoveDir   verticalVelocity     impulseForce   continousForce
  (+ verticalVelocity)  gravity
```

### 상태 필드 (초록 = 데이터)
| 필드 | 소비처 |
|---|---|
| `MoveDir` | HandleMovement |
| `verticalVelocity` | HandleMovement / HandleGravity |
| `gravity` | HandleGravity |
| `impulseForce` | HandleExternalForces |
| `continousForce` | HandleExternalForces · ApplyVelocity |

### 입력원

| 구분 | 진입 함수 | 갱신 필드 |
|---|---|---|
| **내부** | `Move` | MoveDir |
| **내부** | `Jump` | verticalVelocity |
| **내부** | `Dash` | impulseForce (또는 MoveDir 계열) |
| **외부** | `AddImpulse` | impulseForce |
| **외부** | `AddForce` | continousForce |

> 내부 = 플레이어 자신의 조작, 외부 = 피격 넉백 등 타 시스템이 밀어넣는 힘.

## 플레이어 컨트롤 루틴 (구현 사항)

```
PlayerInput (Unity Input System)
        │
   ┌────┴────┐  입력키 설정 변경
   ▼    ▼    ▼
 UI    Combo   Real
Click  Deck    Time
      Building Combat
        │
        ▼
   PlayerControl
        │  실시간 전투 중?
        ▼
     Command
        │
        ▼
   Entity(Player)
```

- `PlayerInput`은 **입력키 설정 변경**을 분기로 세 가지 컨텍스트를 스위칭한다.
  - UI Click
  - Combo Deck Building (덱 구성)
  - Real Time Combat (실시간 전투)
- `PlayerControl`은 "실시간 전투 중?" 판정 후 `Command`를 만들어 `Entity(Player)`에 전달한다.
- `Setting`(전역 설정 오브젝트)이 `PlayerInput`의 입력키 설정에 연결된다.
