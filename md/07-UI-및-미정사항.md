# 07. UI 및 미정 사항

## 실시간 전투 화면 배치

```
┌─ 가상의 벽 ─┐                                                  ┌─ 가상의 벽 ─┐
│  Attack     │   [몬스터 체력 UI]        [콤보 UI / 히트 수 / 대미지]  │  Attack     │
│  월바운드    │                                                  │  월바운드    │
│             │   Player ──► Attack ──(충돌)── Enemy              │             │
│             │                                                  │             │
│             │   [플레이어 체력/마나 UI]   [동료 스킬 UI]            │             │
└─────────────┘                                                  └─────────────┘
```

- **가상의 벽**: 좌우 끝에 `Attack` 컴포넌트를 붙여 **월바운드** 처리.

## UI 목록

| UI | 위치 | 비고 |
|---|---|---|
| 몬스터 체력 UI | 실시간 전투 | |
| 플레이어 체력/마나 UI | 실시간 전투 하단 좌 | |
| 동료 스킬 UI | 실시간 전투 하단 중앙 | |
| 콤보 UI (히트 수, 대미지) | 실시간 전투 우측 | |
| 체력 UI | 공격 파트 | 피격자 `Health` 구독 |
| 불렛타임 슬롯 ui | 불렛타임 | `MagazineUI` *임시 |
| 손패 ui | 불렛타임 | `Skill Palatte UI` *임시 |
| 게임 시작 버튼 / 게임 종료 버튼 | 메인화면 | |

## 미정 · 검토 필요 항목

### 공격범위 / 타겟팅
- **자동?** — 대신 타겟지정을 자알 해줘야 함
- **수동?** — (강조 표시됨)

### 스킬 사용
- 방식 미정 (섹션만 존재, 내용 비어 있음)

### 기타
- `PlayerUnlockedSkills` 자료구조 미정 — "뭘로 해야할지 모르겠음"
- `AudioManager` — 프로토타입에서는 보류
- `SaveManager` — 프로토타입에서는 구현 x, 매 시작마다 초기화
- `GameManager` — 프로토타입에서는 구현 필요 없음
