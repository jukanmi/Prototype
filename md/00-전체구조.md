# 00. 전체 구조

## 캔버스 배치

다이어그램은 크게 3개 층으로 배치되어 있다.

```
[상단]  전역 매니저 오브젝트들 (GameManager / SceneLoader / AudioManager /
        SaveManager / BattleSceneController) + 도형 도움말 + Setting

[중단]  물리 파트 │ 공격 파트 │ 메인화면 │ 스테이지 진입(Init) │ 인게임(적 생성 · 불렛 타임 · 실시간 전투)

[하단]  구현 사항 : 플레이어 컨트롤 루틴 │ 스킬(덱)관리 파트 │ 몬스터(Enemy) 관련 코드들
        + 미정 메모(스킬 사용 / 공격범위 자동·수동)
```

## 도형 도움말 (범례)

| 도형 | 의미 |
|---|---|
| 빨간 라운드 박스 | 상태 첫 진입 (진입점) |
| 노란 사각 박스 | 객체 |
| 파란 박스 | 함수 / 처리 / 설명 |
| 파란 마름모 | 분기 · 판정 |
| 초록 박스 | 데이터 · 필드 |
| 회색 박스 | UI |

## 시스템 목록

- **전역 매니저**: GameManager, SceneLoader, AudioManager, SaveManager, ObjectPoolRoot
- **씬 컨트롤러**: BattleSceneController
- **플레이어**: PlayerInput(Unity Input System), PlayerControl, Entity(Player), CombatPhysics
- **전투**: Combat, Attack, Health, Energies, CombatState, HitData/HitInfo, DamageData
- **불렛타임**: BulletTimeManager, MagazineController, SpellMagazine, SkillExecutor, SpellData
- **덱**: PlayerUnlockedSkills, PlayerDeck, Hand, Discard, CardDraw, MakeACard
- **몬스터**: Enemy, EnemyAI, EnemyAttack, TargetFinder, IEnemyState(Chase/Attack/Cooldown)
