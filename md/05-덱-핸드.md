# 05. 스킬(덱) 관리 파트

## 핸드생성 루틴

```
PlayerUnlockedSkills           플레이어가 설정한 카드덱
(획득한 스킬들을 따로            ────────────────────►   첫 전투 진입
 관리하고 싶다면 구현)                                      진입
   └ 스킬(카드) 해금정보                                     │
     자료구조는 뭘로 해야할지 모르겠음.                        ▼
     일단 모든 스킬 중에 플레이어가                    PlayerDeck에서 카드를 불러옴
     해금한다면 이곳에서 스킬 변동사항을 관리함.                │
                                                          ▼
                                                   랜덤으로 Suffle 진행
```

### MakeACard (아케인트리거 대장간)
- 경험치 모이면 카드 생성 (일단 `ObjectPoolR`(ObjectPoolRoot) 사용)

## 스킬 사용 루틴

```
[스킬]
   │
   ▼
Hand에서 pop하고
Discard에 사용한 스킬 저장
   │
   ▼
◇ HandCardCount <= 0 ?
   │ N ──────────────────────────────────────────────► 종료
   │ Y
   ▼
◇ DeckCount <= 0 ?
   │ Y ──► Discard에서 모든 카드 불러오고 Discard.clear ──► Deck Suffle ──┐
   │ N                                                                  │
   ▼                                                                    │
Deck에서 Hand로 드로우  ◄──────────────────────────────────────────────┘
   │
   ▼
 종료
```

### 컬렉션
| 이름 | 역할 |
|---|---|
| `PlayerUnlockedSkills` | 해금한 스킬 전체 (구현 여부 미정) |
| `PlayerDeck` / `Deck` | 이번 런에서 쓸 카드덱 |
| `Hand` | 현재 손패 |
| `Discard` | 사용한 스킬 버림더미 |
