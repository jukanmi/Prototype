# 01. 부트 · 씬 · 전역 매니저

## 전역 매니저 (앱 실행 시 메인화면 씬에 생성)

| 매니저 | 역할 | 프로토타입 범위 |
|---|---|---|
| **GameManager** | 런 데이터(스테이지 인덱스, 덱, 플레이어 스탯, 경험치) 보관 | 구현 필요 없음 |
| **SceneLoader** | 씬 로드/언로드 및 페이드 연출 담당 | 메인화면 씬을 끄지 않고 인게임 씬으로 이동 |
| **AudioManager** | BGM / SFX 소스 | 보류 |
| **SaveManager** | 세이브 파일 읽기 | 프로토타입에선 구현 x, 매 시작마다 초기화됨 |
| **ObjectPoolRoot** | 카드 / 적 / 이펙트 풀. 여기 두면 씬 전환에도 살아남음 | 사용 |

### GameManager 보유 데이터 (프로토타입 값)
- 스테이지 인덱스 : `1` (프로토타입)
- 플레이어 스탯 : 1레벨, 기본캐 (프로토타입)

## 메인화면

```
앱 실행
  └─ 메인화면 씬 생성
       ├─ GameManager
       ├─ SceneLoader
       ├─ AudioManager
       ├─ ObjectPoolRoot (카드 / 이펙트 / 적)
       └─ SaveManager
```

### 그 외의 메인화면 구성 UI
- 게임 시작 버튼
- 게임 종료 버튼

## 스테이지 진입 = 인게임 씬 초기화(Init)

메인화면 씬은 **백그라운드에 존재**한다. `SceneLoader`의 `LoadSceneMode.Additive`에
의해 인게임 씬만 위로 올라간 상태.

```
[메인화면 씬 - 살아있음]
  GameManager   SceneLoader
  AudioManager  ObjectPoolRoot
  SaveManager

시작 버튼 눌러서 인게임 진입
        │
        ▼
  BattleSceneController
```

### BattleSceneController
- 인스펙터로 연결된 매니저들 참조 확보
  (`GridManager`, `TurnManager`, `DeckManager`, `EnemySpawner`, `UIManager`)
- `GameManager`에서 런 데이터 읽어 플레이어에 주입
- UI ↔ 플레이어, 카메라 ↔ 플레이어 바인딩 (**여기서 한 번만**)
- 몬스터가 우측에서 기어나오게 출발시킴

### 플레이어 (프리팹으로 존재)
```
PlayerInput
    │
    ▼
핸드생성 ── CardDraw
```
