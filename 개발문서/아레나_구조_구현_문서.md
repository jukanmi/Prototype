# 아레나 구조 구현 문서

> **컴파일 상태**: 런타임 및 에디터 어셈블리 Roslyn 컴파일 확인 완료 (에러 0)

## 1. 스테이지 구성 및 경로

| 스테이지 | 구성 내용 | 비고 |
| :--- | :--- | :--- |
| **Stage_01** | 웨이브 · 입문 (전사만) | |
| **Stage_02** | 아레나 2개 + 통로 | 구 Stage_02 + Stage_03 병합 |
| **Stage_03** | 웨이브 · 역할군 조합 | 구 Stage_04 |
| **Stage_04** | 웨이브 · 총력전 | 구 Stage_05 |

* **씬 및 빌드 세팅 정리**: `Stage_05.unity` 삭제 완료, `Boot` 씬 및 Build Settings를 4개 스테이지 기준으로 재정렬.

## 2. Stage_02 구조

```text
[아레나 1 / 1R] (x: -6 ~ 6) ── 통로 (Path ×2) (x: 6 ~ 32.7) ── [아레나 2 / 2R] (x: 32.7 ~ 44.7)
```

- **통로 길이 산출 기준**:
  - 화면 폭의 1.5배를 목표로 타일 수 계산.
  - **핵심 제약**: 통로 길이가 화면보다 짧으면 카메라 클램프가 한 점으로 접혀 스크롤이 발생하지 않음 (Path 1장(13.4)으로는 부족하여 Path ×2장 적용).

---

## 3. 경계 및 카메라 제어 (StageBounds)

- **경계 소유 구조**:
  - `StageBounds`가 단일 경계값을 관리하며, 카메라에는 별도의 아레나/통로 분기 로직이 없음.
  - 구간이 화면보다 좁을 경우 카메라 클램프가 자연스럽게 한 점으로 접히는 계산 방식(`ClampToSection`) 적용.
- **보간 및 시간 축 처리**:
  - 전환 시간 **0.3초 보간**, `LateUpdate`, `unscaledTime` 적용.
  - *이유*: 라운드 종료(마지막 적 사망) 시 발생하는 불릿타임 구간에서 게임 시간(`Time.timeScale`) 기준으로 보간할 경우 카메라가 굳는 현상 방지.
- **카메라 vs 유닛 경계 적용 차이**:
  - **카메라 경계**: 0.3초 동안 부드럽게 보간.
  - **유닛 경계**: 즉시 갱신. (스폰 계획이 보간 중인 값을 참조하면 0.3초 동안 적이 엉뚱한 위치에 스폰되는 문제 방지).

## 4. 벽 뒤 몬스터 스폰 연출

- **진행 플로우**: `예고(0.8초)` → `진입` → `전투`
- **진입 중 `EnemySpawnGuard` 제어**:
  - **몸통 콜라이더 OFF**: 벽 안쪽에서 피격 및 공격 불가.
  - **`Entity.IsTargetable = false`**: `BattleRegistry`의 모든 조준/타겟팅 함수에서 제외.
  - **`BeltScrollView.SortingOffset = -30000`**: 배경 오브젝트보다 뒤에서 렌더링되며, 진입선을 넘는 순간 `0`으로 복귀.
- **스폰 규칙**:
  - 스태거 0.25초.
  - **1R**: 정면 스폰.
  - **2R**: 좌/우 양방향 스폰.

## 5. 라운드 클리어 판정 (RoundClearRules)

- **클리어 조건**: `예약분` + `진입 중` + `전투 중` 카운트가 모두 **0**일 때만 라운드 클리어 처리.
- **사망 연출 처리**: 사망 연출 중인 적은 카운트에서 제외하되 오브젝트는 유지.
- **테스트 커버리지**:
  - 조기 종료 방지 ("클리어 판정 후 추가 적 출현 방지")
  - 지연 종료 방지 ("모든 적 처치 후 미종료 현상 방지")

## 6. 기타 개선 사항

### AllyControl 포메이션 추종
- **배경**: 기존 동료 AI가 적만 추적하도록 되어 있어, 적이 없는 통로 구간에서 동료가 대기 상태로 멈추는 문제 발생 (방치 시 리더만 아레나 2에 진입 후 문이 닫혀 고립됨).
- **개선**:
  - 비전투/이동 시 리더의 포메이션을 추종하도록 개선.
  - 리더의 이동 방향에 따라 대형이 좌우로 자동 반전.

### 정비 및 보상 구간 (ArenaDirector)
- `ArenaDirector.EnterMaintenance()`에 2.5초 대기 구간 및 `TODO` 구현 상태.

## 8. 인게임 검증 체크리스트

- [ ] **통로 스크롤**: 데드존 밖으로 이동할 때 카메라가 튀지 않고 부드럽게 스크롤되는지
- [ ] **아레나 락**: 진입 순간 문이 닫히고 카메라가 중앙에 고정되는지 (12폭 아레나 기준 16:9 해상도 좌우 여백 확인)
- [ ] **벽 등장 연출**: 예고 표식 발생 후 배경 뒤에서 적이 걸어나오며, 진입 중 광역기/타겟팅에 면역인지
- [ ] **아레나 2 좌측 스폰**: 닫힌 입구 문 위치에서 적이 자연스럽게 스폰되는지
- [ ] **동료 추종**: 통로 이동 시 동료들이 대형을 유지하며 따라오고 뭉치지 않는지
