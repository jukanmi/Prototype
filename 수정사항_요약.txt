■ 3. 버그 수정 — 다단히트 근접 스킬 2타 이후 데미지 누락
--------------------------------------------------------------------
대상 파일: Assets/Scripts/Entities/Attack.cs (Begin 메서드)

증상: "스킬 데미지가 적에게 제대로 들어가지 않는 것 같음"

원인:
  - 근접 히트박스는 Collider.OnTriggerEnter로만 판정
  - SkillState.FireNextHit()이 다단히트마다 Attack.Begin()을 재호출
  - Begin()은 box.enabled = true를 다시 대입할 뿐인데, 콜라이더가
    이미 true인 상태에서 true를 다시 대입해도 유니티는
    OnTriggerEnter를 재발화하지 않음
  - 첫 타 이후 적이 히트박스를 벗어났다가 다시 들어오지 않는 한
    (넉백이 작은 콤보 히트일수록 확실히 안 벗어남) 2타 · 3타는
    판정 자체가 발생하지 않아 데미지가 0으로 누락됨

가장 크게 영향받던 스킬: 올려베기(SK_WR1B, 전사, 근접 3히트)
  - 1타(11)만 들어가고 2 · 3타(11+14=25)가 누락되는 상태였음
  - 궁수/마법사의 다단히트 스킬(연속 사격, 마력탄 연사)은 투사체
    방식이라 매 타마다 새 오브젝트가 생성되므로 이 버그의 영향
    없음 — 정상 작동

수정 내용:
  Begin()에서 box.enabled = true를 대입하기 전에
  box.enabled = false를 한 번 거쳐 강제로 재진입(OnTriggerEnter)이
  발생하도록 변경

  변경 전:
    box.enabled = true;

  변경 후:
    box.enabled = false;
    box.enabled = true;

※ 프로젝트 규칙상(CLAUDE.md) 테스트 실행은 하지 않음.
  씬을 플레이해서 아래 항목을 직접 눈으로 확인 필요:
  1. 올려베기(SK_WR1B)로 적을 때렸을 때 3타 모두 데미지가 들어가는지
     (BattleLog에 "2/3타 발동", "3/3타 발동"과 함께 각 타마다
     "적중 | dmg ..." 로그가 찍히는지)
  2. 다른 유형 스킬(단일히트 / 투사체 / 장판형)에 회귀가 없는지

■ 4. 추가로 발견했지만 아직 손대지 않은 사항
--------------------------------------------------------------------
- 적이 Down/Getup 상태일 때 HitData.canOtg가 꺼진 스킬로 맞히면
  의도적으로 데미지가 0으로 무효화됨 (다운 상태 무적 설계)
- 현재 16개 스킬 전부 canOtg: false — 다운된 적 추가타가 항상
  무효 처리되는 상태. 의도된 설계인지 확인 필요
  (사용자가 겪은 "데미지 안 들어감" 현상이 이쪽일 가능성도 있음)
